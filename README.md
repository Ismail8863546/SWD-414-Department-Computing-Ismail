# Department of Computing Website

A simple responsive multi-page website created for the SWD 414 Git and GitHub assignment.

## Pages
- `index.html` — homepage
- `about.html` — department information
- `programmes.html` — available programmes
- `contact.html` — contact form layout

## Run locally
Open `index.html` in a web browser. No framework or package installation is required.

## Git workflow
The project history includes multiple commits and a `feature/contact-page` branch merged into `main`.
